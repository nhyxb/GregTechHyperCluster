## 三、服务端 Token 账本 `CloudTokenLedger`（SavedData，单一持久化边界）

**账户**：按**同一世界存档内的玩家 UUID** 独立记账，余额 `long` 整数，全部增减仅由服务端 `CloudTokenLedger` 执行；账本挂在**主世界（overworld）`DimensionDataStorage`**（`hypercluster_cloud_ledger`），因此**跨卫星站、跨维度共享**。

- **一次性体验金**：首次在**任意**地面站开户（凭据卡插入任意站点）自动发放 **5,000,000** 体验 Token；`welcomeClaimed` 标志随账本 NBT 持久化 ⇒ 跨多座卫星站、跨维度、跨存档重启**严格只领一次**（GameTest：双站不重发、账本 NBT 往返后仍拒绝重发、另一玩家独立领取）。
- **订单计费契约**（`hold / settle / release` 三态 + 唯一订单 ID 去重）：
  - `hold(owner, orderId, amount)`：预扣。订单 ID 已存在时**去重不双扣**（HELD→`ALREADY_HELD` 恢复执行、SETTLED→`ALREADY_SETTLED` 不再扣费）；余额不足 → `INSUFFICIENT` **拒绝启动且分文不动**；
  - `settle(orderId)`：轮次完成，HELD→SETTLED，累计消费 +price（驱动并发档位）；幂等，已结算不二次结算；
  - `release(orderId)`：失败/取消，**仅 HELD 可释放**（精确退还预扣），SETTLED 永不退款、REFUNDED 永不二次退款 —— **不吞单不双扣**；
  - 订单簿与账户共享同一 SavedData 持久化边界，有界（≤512 条，HELD 订单永不淘汰）。
- **会话（429）**：云端轮次运行期间账户持有 1 个会话；并发上限 = 账户档位（累计消费 0/50 万/200 万/500 万/2000 万 Token → **Tier 1–5 → 1–5 并发**）；超限 `beginSession` 拒绝 → 站点报 **429 暂停**且**不计费**。会话为**运行态不持久化**：重启自动清零，绝不留死锁；已完成扣费的轮次在重载后仅重取会话、永不被 429 卡死。
- **提示词缓存指针**：`lastCacheKey + hits` 同为运行态（重启冷启动，不残留折扣）。
- **NBT 往返**（GameTest `ledgerContractOrdersAndPersistence`）：余额/累计消费/欢迎标志/订单簿全量持久化，缓存指针与会话重载后为空。

## 四、API 卫星地面站 `hypercluster:api_satellite_station`

- **结构**：固定 3×3×3（`start(RIGHT, UP, BACK)`，朝北时）：`"FSF"/"FPF"/"F#F"`（前）+ `"FPF"/"PPP"/"FHF"`（中，馈源顶面中心）+ `"FFF"/"FPF"/"FFF"`（后，钢架位可替换为能源仓×1–2 / 维护仓 / **兜底网关 ×0–1**）。外观块＝卫星站钢架（`block/cloud/satellite_dish_frame`），主控模型＝钢架贴图 + `overlay_front(.active)`，工作态渲染同步已入 `registerRenderStates()`。
- **轻资产供电**：仅需 **LV 或 MV 能源仓**即可驱动（Medium 轮次 30 EU/t ∈ LV、Extra High 120 EU/t ∈ MV、本地兜底 60 EU/t）——GameTest 分别用 LV/MV 能源仓实测驱动。
- **露天校验**：馈源必须**露天直视天空**（从馈源上方逐格扫描实体渲染方块）：被遮挡 → **拒绝联机**（`SKY_BLOCKED`，云端与兜底一并不启动，非兜底触发条件）；雷雨**信号衰减**：雨 ×1.5 耗时、雷暴 ×2.0 耗时；**`Y > 120` 小幅延迟/费率优化**：耗时 ×0.9、账单 ×0.95（纯函数由 GameTest 断言边界 120/121）。
- **数据变现**：凭据卡在场时，上传槽的高纯数据集**自动整组出售**——高纯矿处 50,000/份、高纯化工 50,000/份，整数 Token 记入绑定账户（GameTest 实测 2+3 份共 +250,000 且槽清空）；`token_credit_card` 支持整额**存入/取出**（GameTest 存 50 万 → 取空账户 → 再存回）。
- **本地模拟闭源服务（先只管示范任务）**：1 清洁数据集 → 1 高纯矿处数据集（稳定 ID `hypercluster:cloud_scrub_demo`，内部轮次引擎，不占用 GT 配方逻辑）。计费规则全部为**纯静态可测**（`CloudPricing`）：
  1. **Prompt Caching**：缓存键 = `(playerUuid, machinePos, recipeId, modelId, tier)`；同键**连续命中从第 2 轮起 Token 费率 10%**；任一维度变化**立即失效重算**（tier 换档 / 换模型 / 换站位置 / 他站轮次顶掉指针，GameTest 全部实测）；
  2. **Batch 模式**：勾选后**耗时 ×2、Token 账单 ×0.5**；**与缓存叠加规则（代码 `CloudPricing.taskPrice` 与本报告双写）：乘法叠加** —— 缓存命中且批处理 = 基准 × 0.1 × 0.5 = **5%**（GameTest 实测 1,250 Token = 25,000 × 5%，耗时仍 ×2 = 200 tick）；
  3. **推理档位（Medium / Extra High）**：Medium 单价 ×1 / 耗时 ×1 / 30 EU/t；Extra High 单价 ×2 / 耗时 ×0.5（更快）/ 120 EU/t；
  4. **429 并发限流与 Leaving Soon 生命周期**：见上/下节；**模型目录**（`CloudModels`）：`hypercluster:omni_flash`（OmniFlash-72B，永不下线）与 `hypercluster:legacy_llama`（LegacyLlama-8B，生命周期演示款，**基于游戏日**的可配置弃用：`-Dhypercluster.legacyRetireDay`（默认 3）/ `-Dhypercluster.leavingSoonDays`（默认 1）；**LEAVING_SOON 状态仍可启动新轮次并显示倒计时，倒计时归零（RETIRED）后云端轮次被拦截且不计费**，GameTest 三态全实测）。
- **计费全生命周期**（GameTest 逐一断言）：余额不足**拒绝启动**（0 扣费）；启动即预扣（订单 HELD）；完成 settle（扣费转累计消费）；**取消精确退还**（HELD→REFUNDED，余额恢复原值，已耗输入返还输入槽，计 0 消费）；**存档/读档中途往返**后轮次原订单恢复、**结算恰好一次**（订单 ID 去重 ALREADY_SETTLED，双保险断言）。

## 五、本地 Fallback 兜底网关 `hypercluster:local_fallback_gateway`

- **IV 级被动部件**（`MultiblockPartMachine`，PartAbility `hypercluster:local_fallback_gateway`，结构 0–1 个）：接入地面站钢架后待命。
- **无缝兜底**：当云端轮次触发 **429 限流**、**Token 余额不足**或**型号 Leaving Soon 到期下线**时，站点**当场切换本地降速兜底模式继续同一任务**：耗时 ×4、EU 60/t（本地电），**Token 零计费、不占并发会话**，产物照常产出 —— 产线**不硬卡死**（GameTest：空余额 → 兜底轮次 ×4 耗时、产出照常、网关计数 +1、余额分文未动）。
- **非兜底条件**：馈源被遮挡（物理断链）不属于兜底范畴 —— 无链可兜，站点直接拒绝新轮次直至重见天空（GameTest 遮挡/复通实测）。

## 七、验收环境注意（长期有效，已记入 MEMORY.md）

1. **`run/gametest/server.properties` 的 `level-type` 必须为 `minecraft:flat`**：gametest 场地固定在 y=-60，`normal` 世界下其上方是天然深板岩层，任何露天/天空判定（`canSeeSky`、馈源露天校验）会随机按地形被挡。本次已改为 flat 并验证全绿；**旧 `run/gametest/world` 含天然地形与历史残留结构，已在验收前删除**。
2. **gametest 世界在多次 `runGametest` 之间持久化**（同一 `run/gametest` 目录）：依赖世界级全局状态（SavedData）的测试必须使用**每测试随机 UUID/订单 ID**；0.4 云批次全部按**单例批次**（`hypercluster_04_cloud_NN_*`）串行运行。
3. 测试内 `System.out` 诊断走 gradle 控制台（stdout）而非 `latest.log`，排查时须抓 gradle 输出。
