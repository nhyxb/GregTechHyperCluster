# 0.5.0 视觉与结构升级验收

基线为 `main @ 3859c70`，运行组合为 Minecraft 1.20.1、Forge 47.4.0 与 GTCEu 7.4.0。四座机器保留原注册 ID，更新旧存档后需按新形状重新搭建。这一版使用 GTCEu 的结构谓词、渲染状态及原版客户端粒子，未引入 Mixin。

六台控制器均在客户端的 `animateTick` 中检查同步的 `RECIPE_LOGIC_STATUS == WORKING`。六套工作贴图每套 4 或 6 帧，每帧 2 或 3 tick。已核对 `Public/` 原稿、运行资源与成品 JAR 内的 PNG 和动画元数据逐字节一致，并确认六个生成模型的工作态引用各自的动画贴图。

## 悬停说明修复

GTCEu 的 `MetaMachineBlock#appendHoverText` 会根据机器 ID 自动插入主描述。移除注册时对同一翻译键的第二次添加后，物品仍保留电压、储能等附加说明。`SurvivalCraftingTests.machineDescriptionTooltipsNotDuplicated` 逐台调用实际悬停 API，检查描述存在且只出现一次。JAR 内另核对了 11 个中文主描述键。
