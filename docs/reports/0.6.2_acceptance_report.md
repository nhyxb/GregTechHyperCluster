# 0.6.2 架构格雷化验收报告

2026-11-28（Asia/Shanghai） · Minecraft 1.20.1 · Forge 47.4.0 · GTCEu 7.4.0

## 交付范围

以 `33f3d5d` 的 0.6.1 功能为基线，保留 `e9bdc7f` 的 TB 单位修正。原先的 `b8303e7` 随 Git 历史保留，其中提前接通的六大模型结算在本次交付中撤回，留给 0.6.3。本版通过 GTCEu 能力、Forge 事件和原生光路扩展点实现。

- 张量预训练集群从标准物品输入总线消耗一份高纯数据集，并从输出总线交付带训练标签的权重模块。输出满时检查点保持在 100%，卸出物品后自动交付一次。
- API 卫星地面站从标准物品输入总线出售矿业与化工高纯数据集，每份 50,000 Token。示范轮次也走标准输入和输出总线，满仓等候交付。主控保留凭据卡、Token 晶卡和档位、Batch、模型设置。
- 风冷、液冷、显存及 MoE 机柜可在外露机壳格安装一座机房硬件仓。仓口按物品类型分配槽位，并通过 Forge 物品能力接受自动装卸。旧世界可以安装仓口访问原有硬件库存。
- 房内暗线要求整座底座直接压在同高、正交连通的实心架空地板矩形内。短边至少 5 格，长边至多 24 格，长宽比至多 3:1。方块、区块或成型状态变化后才重新计算几何和成员关系。
- 出房光路使用 GTCEu 原生算力传输仓、连续光学管道与算力接收仓。交换机聚合地板内的机柜和真实光路来源，光路也可从源交换机传递在线显存。交换机带宽为 128 CWU/t，超限触发 503，冷却 300 tick。
- 中英 Patchouli 第四、五、六章同步更新，第三章的风冷机柜条目也同步了硬件仓用法。[MEMORY.md](../../MEMORY.md) 记录了两条机房工程规范。
