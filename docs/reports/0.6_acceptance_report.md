# 0.6.0 LuV 智算与训练核心闭环验收

基线为 `main @ 814b34f`（0.5.0），运行组合为 Minecraft 1.20.1、Forge 47.4.0 与 GTCEu 7.4.0。本版新增冷板液冷算力机柜、UPS 蓄电池配电矩阵、张量预训练集群与云算力外包节点，全部复用 GTCEu 原生能力，未引入 Mixin。

## 交付内容

### 结构与物品

| 注册 ID | 类型 | 说明 |
| --- | --- | --- |
| `hypercluster:liquid_rack_casing` | 方块 | 冷板液冷机柜外壳，接入 LDLib 原生读图 CTM（16×16 基础图 + 32×32 连接图 + `.png.mcmeta`） |
| `hypercluster:ups_battery_casing` | 方块 | UPS 蓄电池外壳，同样走原生 CTM 模板 |
| `hypercluster:luv_liquid_blade` | 物品 | 每枚 16 CWU/t + 24 GB 显存，堆叠 64，中英 Tooltip |
| `hypercluster:open_weight_module` | 物品 | 训练产物，NBT 携带领域 / 精度 / 版本三项 |

美术直接采用 `Public/` 中随本版交付的 0.6.0 正式贴图与动画（4 台机器共 8 张 overlay，其中 `tensor_pretraining_cluster` 为 6 帧 96px 竖条），无占位图。CTM 配置沿用 0.4.1 确立的模板：`<name>.png.mcmeta` 指向 `hypercluster:block/datacenter/<name>_ctm`。

### 四座多方块

| 多方块 | 尺寸 | 控制器 | 关键契约 |
| --- | --- | --- | --- |
| 冷板液冷算力机柜 | 5×5×3 | 正面第二层 `(2,2,0)` | 4 液冷刀片 0→**64 CWU/t**；每 tick 喝 1 mB 冷却液（蒸馏水 ×1.00 / PCB 冷却液 ×0.85）；中性环境 **PUE 1.20**；交换机带宽 64 CWU/t、显存 24 GB/刀片（满插 96 GB） |
| UPS 蓄电池配电矩阵 | 5×4×3 | 正面第二层 `(2,1,0)` | 电网正常浮充 4096 EU/t，满电 4,000,000 EU；掉电以 8192 EU/t 放电，提供 **60 秒（1200 ticks）** 备电；电量写档不丢 |
| 张量预训练集群 | 7×6×7 | 第 2 层正面 `(2,1,0)` | 2400 ticks 长周期；每 **25%** 落一次 NBT Checkpoint；显存不足 **OOM 拒绝启动**；无 UPS 覆盖掉电清零未保存进度；完成后产出 `open_weight_module` |
| 云算力外包节点 | LuV 部件 | 挂机柜柜壁，每柜≤1 | 按真实租出 CWU/t × (1.20 ÷ PUE) 打入 Token；**同 tick 实扣预算，绝不双花**；断缆/断冷/拆结构/卸载当 tick 停发 |

三座主结构均为非火柴盒造型：机柜是双排冷热通道 + 顶部光缆桥架；UPS 是电池组夹母排检修通道 + 钢结构顶桁架；预训练集群为**阶梯收腰**——重型底座、中段缩进一圈的大面积玻璃核心视窗（内含高级计算机机壳算力柱）、重新外扩的肩部与仅留屋顶边缘的钨钢散热环梁。四台机器均有客户端 `WORKING` 粒子与动画工作贴图，并全部纳入 `registerRenderStates()`。

## 交互与界面

四台机器的 GUI 全部复用 `MachineUi`，`MachineUiTests` 为新增界面补齐断言：机柜 5 槽 + 2 标签、预训练集群 1 槽 + 2 标签、外包节点标签/槽/状态面板三段式，均通过包围盒内嵌与最小 3 px 净距检查。

### 新增 GameTest 覆盖

| 用例 | 断言要点 |
| --- | --- |
| `liquidRackScalesTo64Cwu` | 0→16→32→48→64 CWU/t 线性；96 GB 显存；中性 PUE 1.20、低温环境 1.12 |

| `upsContractKeepsCheckpoint` | 1200 ticks=60s、25% 里程碑、跨档判定；UPS 浮充→放电→耗尽后不再提供保护 |
| `oomGateRefusesOversizedJob` | 0 GB 主机拒绝 96 GB 任务（OOM）；接入 96 GB 机柜后闸门放开 |
| `offloadPaysTokensWithoutDoubleSpend` | 租出 64 CWU/t 得 2743 Token 并入账；同 tick 本地/科研请求均只得 0 |
| `checkpointSurvivesSaveLoad` | `checkpointPercent` / `totalTicks` 经存档往返不丢；模块三项 NBT 正确 |
