# GregTech HyperCluster 0.1 生存操作流程

> 本流程只使用 0.1.0 已实现的功能：**HV 遥测示范洗矿机**（精确遥测结算 + 日志缓冲）、
> **HV 微型烧录台**（日志 + 载体 → 芯片）、**矿处边缘芯片省水洗矿配方**。
> 全程纯生存可达成，无需任何指令；所有配方均可在 JEI/配方浏览器查到。

## 0. 前置（正常 GT 进度）

- HV 档电力与常规 GT 材料：HV 机器外壳（`gtceu:hv_machine_hull`）、HV 电路（高级集成电路）、
  金线缆、HV 传感器、HV 发射器、玻璃、聚乙烯板、硅晶圆（`gtceu:silicon_wafer`）。
- 一台**原版 HV 洗矿机**（`gtceu:hv_ore_washer`）——升级为遥测洗矿机的原料。
- 破碎铜矿石（`crushed_copper_ore`）、水、可在 GT 工作台使用的手钻/扳手等常规工具。

## 1. 制作空白载体

工作台（JEI 搜 `hypercluster:blank_carrier`）：

```
聚乙烯板  硅晶圆  聚乙烯板
聚乙烯板  HV电路  聚乙烯板      → 2× 空白载体
```

## 2. 制作微型烧录台

工作台（JEI 搜 `hypercluster:hv_micro_burner`）：

```
HV发射器  HV电路  HV发射器
玻璃     HV机壳   玻璃      → 1× HV 微型烧录台
金线缆   HV电路   金线缆
```

## 3. 把原版洗矿机升级为遥测洗矿机

工作台（JEI 搜 `hypercluster:hv_telemetry_ore_washer`）：

```
        HV传感器
HV电路  原版HV洗矿机  HV电路    → 1× HV 遥测示范洗矿机
玻璃     金线缆      玻璃
```

## 4. 采集遥测日志

1. 放置遥测洗矿机，接好 HV 电源（电池槽放 HV 电池或拉 HV 线缆）。
2. 输入槽放**破碎铜矿石**，水槽进水 ≥1000mB，电路槽设为**编程电路 1**。
3. 机器开始工作（正面贴图变为运行态）。每成功结算一批：
   - 产物槽：1×纯净破碎铜矿石 + 1×石粉（约 1/3 概率多一份钴粉）；
   - **日志缓冲槽 +1 矿处遥测日志**（GUI 右下方的独立槽位，悬停显示 `n / 64`）。
4. 从缓冲槽取日志即可。注意：
   - 缓冲满 64 后机器照常加工，但**新日志会被丢弃**（悬停会提示“缓冲已满”）；
   - 用扳手拆走机器会把缓冲内剩余日志**一次性掉落**，重装后从空缓冲开始。

只有“真实落槽”的批次才计 1 份：堵仓、中途取消、断电未完成的批次一律 0 份。
暂停按钮的语义是“完成本批后挂起”，不会丢当前批的日志。

## 5. 烧录边缘芯片

遥测洗矿机旁放一台微型烧录台，同样接 HV 电源：

```
1× 矿处遥测日志 + 1× 空白载体   →（约 128 tick，512 EU/t）→  1× 矿处边缘芯片
```

JEI 搜 `hypercluster:micro_burner` 配方页可见。

## 6. 用芯片解锁省水洗矿配方

回到遥测洗矿机：

1. 电路槽设为**编程电路 2**；
2. 输入槽：1×破碎铜矿石 + **1×矿处边缘芯片**（放在第二个输入槽）；
3. 水槽进 **100 mB** 水（JEI 里与基础配方并排对照：省水 90%）。

芯片**不消耗**：批次结束后原样留在输入槽，可随时取回。
产物与基础版完全一致（1 纯净破碎铜矿石 + 1 石粉 ± 1/3 钴粉），同样计 1 份遥测日志。

## 7. 效益对照（JEI / 机器界面可直接核对）

| 配方 | 电路 | 水 | 产物 | 说明 |
| --- | --- | --- | --- | --- |
| 基础洗矿（镜像自 GT 原版） | 1 | 1000 mB | 纯净铜矿 + 石粉 | 与原版 HV 洗矿机一致 |
| 芯片增强洗矿 | 2（+芯片不消耗） | **100 mB** | 与基础版一致 | 每批省 90% 水，芯片反复可用 |

## 常见问答

- **为什么每种日志都在缓冲槽而不在产物槽？** 日志由结算逻辑单独入账，与配方产物互不影响；
  拆机返还的也只是日志。
- **换存档/区块重载会丢或刷日志吗？** 缓冲随方块实体持久化，重启、卸载、多人访问下不重复、
  不丢失（对应 GameTest `bufferPersistenceNoDuplication`）。
- **芯片会被烧掉吗？** 不会。芯片是 `notConsumable` 输入，批次结束后原样可取回。
